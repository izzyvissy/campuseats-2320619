# Week 1 reflection

Answer each question in 1–3 sentences, in your own words.

1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?
- plain DOM must performed manually when updating browser how to change UI while React modifies and updates the DOM constantly by rendering website using update state.

2. Why must a component name start with a capital letter?
- easy for React to read and distinguish the components, while lowercase usually are HTML component.

3. What does a fragment <>...</> do, and why not just use a <div>?
- Fragment avoids creating an unnecessary <div> in the DOM. Fragment are wrapper for JSX.

4. Name one benefit of splitting the UI into small components.
- Modularity and flexibility
